# Beat competitive alignment

Updated: 2026-08-01

This matrix is the complete public-capability parity ledger for the pinned
current Komari and DStatus baselines. Every discovered competitor capability
must appear as `Verified`, `Partial`, `Missing`, or an `Intentional exception`
with an explicit safer equivalent and acceptance evidence. Omitting a risky,
operational, recovery, presentation, or minor preference feature is not parity.
Evidence links point to public source files; DStatus does not declare a
repository license, so Beat uses only capability and data-shape observations
and does not copy its implementation.
